### 1. 公開ドキュメント上の入口

ご提示のページ  
`https://www.aem.live/developer/importer`  
は、**AEM Importer の公開上の利用入口**として扱ってよいです。  

公開チュートリアル側の説明では、AEM Importer は **既存サイトのページ DOM を取り込み、Markdown / docx 相当の出力へ変換して、Edge Delivery Services への移行を助けるツール**として説明されています。  
また、**単ページ import の検証後に bulk import へ進む流れ**、**URL リスト投入**、**import.js を使った変換調整**、**大量 URL 時のメモリ注意**などが案内されています。

**Sources:**
- [Site migration to Edge Delivery Service using the Importer](https://experienceleague.adobe.com/en/docs/experience-manager-learn/sites/document-authoring/how-to/migration-using-importer)
- [Bulk importing using the Importer](https://experienceleague.adobe.com/en/docs/experience-manager-learn/sites/document-authoring/how-to/bulk-importing-using-importer)
- [Import Sites into AEM Sites with Edge Delivery Services](https://experienceleague.adobe.com/en/docs/experience-manager-learn/cloud-service/expert-resources/cloud-5/season-3/cloud5-import-sites-to-edge-delivery-services)

### 2. AEM Importer のベース GitHub repo

AEM Importer のコードベースは、実質 **2 repo 構成** です。

|役割|レポジトリ|
|---|---|
|Importer 本体ライブラリ|`https://github.com/adobe/helix-importer`|
|Importer UI / companion web app|`https://github.com/adobe/helix-importer-ui`|

内部 developer guide でも、**ローカル開発時にこの2つを clone する**よう書かれています。  
そのため、**ベース repo は `helix-importer` と `helix-importer-ui` のセット**と考えるのが正確です。

なお、日常会話で **「AEM Importer の repo」** と言う場合は、UI 側である **`helix-importer-ui`** を指していることが多いです。

**Sources:**
- [Importer Tool - Developer Guide](https://wiki.corp.adobe.com/display/AEMSites/Importer+Tool+-+Developer+Guide)
- [Import - Prior art](https://wiki.corp.adobe.com/display/AEMSites/Import+-+Prior+art)
- [Import - AEM Importer Next](https://wiki.corp.adobe.com/display/AEMSites/Import+-+AEM+Importer+Next)

### 3. 公開ドキュメントの内容を踏まえた repo の見え方

公開説明と内部資料を合わせると、役割分担はこうです。

#### `adobe/helix-importer`
- 変換ロジックの中核
- default rules や importer core
- import script から使う基盤側

#### `adobe/helix-importer-ui`
- ブラウザで触る UI
- URL を指定して import を試す
- `import.js` を読み込んで結果確認する
- bulk import の UI 面もここが中心

公開の利用説明は「Importer」という1つの道具として見せていますが、実装上は  
**core = `helix-importer`**  
**tool/UI = `helix-importer-ui`**  
です。

**Sources:**
- [Importer Tool - Developer Guide](https://wiki.corp.adobe.com/display/AEMSites/Importer+Tool+-+Developer+Guide)
- [Site migration to Edge Delivery Service using the Importer](https://experienceleague.adobe.com/en/docs/experience-manager-learn/sites/document-authoring/how-to/migration-using-importer)
- [Bulk importing using the Importer](https://experienceleague.adobe.com/en/docs/experience-manager-learn/sites/document-authoring/how-to/bulk-importing-using-importer)
