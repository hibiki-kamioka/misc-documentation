### ベースとなる GitHub レポジトリ

|用途|レポジトリ|
|---|---|
|Importer 本体ライブラリ|`adobe/helix-importer`|
|Importer UI / 開発者が直接触る companion app|`adobe/helix-importer-ui`|

Wiki の developer guide では、**ローカル開発時にこの 2 repo を clone する**前提になっています。  
また別の wiki では、AEM Importer を **`helix-importer-ui` ベースの companion web application** と説明しています。なので、**日常的に「AEM Importer repo」と言うと `helix-importer-ui` を指すことが多い**ですが、実装の土台としては `helix-importer` もセットです。

### 一言でまとめると

- **ベース repo** は  
  **`helix-importer` + `helix-importer-ui`**

  **`helix-importer-ui`**
- **社内の派生/実験系** は  
  **`import-as-a-service` branch や `git.corp` の AI / mapping 系 repo**
